# dashboard

Next.js dashboard for live Agent runs, kernel events, policy hits, evidence chains, and diagnostics.

Use Node.js 24 LTS (Node.js 22 LTS is also supported). The dashboard tracks
Next.js 16 LTS and React 19; Node.js 20 is no longer a supported project runtime.

Local commands:

```sh
npm ci
npm run typecheck
npm run build
npm audit --audit-level=moderate --registry=https://registry.npmjs.org
npm run dev
```

`next-env.d.ts` is generated by `next typegen`/build and intentionally ignored;
do not edit or commit it.
